# Conforme

Check it before you sign. Take one photo of the morning's supplier delivery notes; Conforme separates each note (SAM 3.1), reads every line with its box on the paper (Muse Spark 1.3), checks every euro in plain code, investigates what doesn't add up, and drafts the claim to the supplier. Every number on screen points to the exact place on the paper it came from.

Built for Meta's Global AI Developer Hackathon (Oct 26 - Nov 4, 2026), track "Build for Your World". All code in this repository was written during the event; the first commit is from Oct 26, 2026, after the kickoff.

Status: day 0 (API smoke tests and scaffolding).

## Privacy
- Standard API mode only. A model allowlist in code rejects any `-contributor` model.
- Real delivery notes from the family restaurant are used only to measure accuracy, on my laptop. They are never committed, shown or uploaded anywhere except the Meta Model API in standard mode. Only aggregate numbers are published.
